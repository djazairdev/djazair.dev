# Designs

Exports of the boards on the djazair.dev design canvas, which stays the source of truth. Desktop boards are 1440 px wide at 1×; phone boards are 390 px wide at 2× (Methodology at 1.5×). Each `-top.png` is the first screen of its board, used as the preview in GitHub issues.

[Section 5 of the implementation plan](../implementation-plan.md#5-designs-and-their-tickets) lists which ticket builds each board. When a board changes, it is re-exported here under the same file name, so the issues always show the current design.

Pages still to design are tracked in [#17](https://github.com/djazairdev/djazair.dev/issues/17).
