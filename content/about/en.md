## Why djazair.dev {#mission}

Algeria had {{accounts}} developer accounts on GitHub in {{quarter}}, {{yoy}} more than a year earlier. djazair.dev makes that growth visible and helps it along, in two ways:

- **The Algeria Developer Index,** a quarterly scorecard of where Algeria stands on GitHub against its neighbours and Africa’s largest developer communities, with every number open to checking.
- **The Project Hub,** which points newcomers to open-source projects with Algerian maintainers, or a clear link to Algeria, whose maintainers have promised to answer.

## Who runs it {#who}

djazair.dev is an independent community project, started in Algeria in 2026 and run in the open on GitHub as [@djazairdev](https://github.com/djazairdev). Anyone can propose a change, report an error or list a project: the [contributing guide](https://github.com/djazairdev/djazair.dev/blob/main/CONTRIBUTING.md) explains how.

**djazair.dev is not affiliated with GitHub,** which doesn’t endorse or sponsor it. The Index uses GitHub’s public Innovation Graph data, which GitHub publishes under CC0.

## Privacy {#privacy}

djazair.dev sets no cookies and asks for no personal data. {{analytics}} If you pick a language with the switcher, your browser remembers it on your device, and nowhere else. The Hub shows issue titles from GitHub, never who opened them. {{hub_ideas}} {{hub_counts}}

## Contact {#contact}

For anything public, such as an error, an idea or a project for the Hub, [open an issue on GitHub](https://github.com/djazairdev/djazair.dev/issues/new/choose). For anything else, write to {{contact}}. To report a security problem, follow the [security policy](https://github.com/djazairdev/djazair.dev/security/policy).
