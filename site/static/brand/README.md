# GitHub logo

`github-invertocat-white.svg` is the unmodified white Invertocat from GitHub’s official logo bundle, downloaded on 8 October 2026:

- Logo assets and usage: https://brand.github.com/foundations/logo
- Original bundle: https://brand.github.com/GitHub_Logos.zip

GitHub’s logo is a trademark of GitHub, Inc. It is used as a social link to the djazairdev organization. The renderer preserves its original path, white fill and viewBox proportions when inlining the mark.
